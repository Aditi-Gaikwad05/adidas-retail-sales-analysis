# adidas-retail-sales-analysis
📌 Project Headline

An Interactive Sales Performance Dashboard using Microsoft Power BI.

📝 Short Description

This project focuses on analyzing Adidas sales data using Power BI. It provides insights into sales performance, regional distribution, product performance, and retailer contributions through interactive visualizations and KPIs.

🎯 Purpose of the Project

The main purpose of this project is to:
Analyze overall sales performance.Track monthly sales trends.Compare sales across different regions.Identify top-performing products.Evaluate retailer-wise sales performance.Support data-driven business decisions.

🛠️ Tech Stack

Microsoft Power BI – Dashboard creation and visualization.
Power Query – Data cleaning and transformation.
DAX – Calculations and measures.
Microsoft Excel / CSV – Data handling.

📂 Data Source

The Adidas sales dataset was obtained from a friend for educational and learning purposes.
The dataset contains sales-related information used to analyze:
Sales amount
Units sold
Operating profit
Operating margin
Product categories
Retailers
Regional sales
Monthly sales trends

💡 Key Learning Outcomes

Understanding data cleaning and transformation.
Creating interactive dashboards in Power BI.
Using DAX for business calculations.
Developing data visualization skills.
Analyzing business performance through KPIs.

👩‍💻 Project Category

Data Analytics | Business Intelligence | Power BI
